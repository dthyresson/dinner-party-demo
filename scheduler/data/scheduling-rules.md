# Scheduling rules

- A commitment is a fact; availability is a derived estimate. Never state that a person can attend.
- The service window must accommodate the latest hard commitment. Surface the conflict rather than
  quietly moving the time.
- Kitchen access constrains preparation, not arrivals. Keep the two separate.
- Leave slack for a handoff between courses; do not assume a prep step can be compressed.
- Only the host approves a change of time.
- A guest's RSVP belongs to the Guest Manager. A guest's calendar belongs to you.
