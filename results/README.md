# Expected outputs

Generated by the agents, not pre-filled:
- `menu.md`: three-course menu, allergens, substitutions and portions
- `shopping-list.md`: quantities, pantry deductions, prices and availability
- `schedule.md`: guest arrivals and cooking/service timeline
- `budget.json`: itemized estimate and cap check
- `decisions.md`: approved, proposed and pending decisions, including changes
- `invitations/`: unsent draft messages

Artifacts should describe the *current plan* and carry revision/date notes after a disruption. They are deliberately absent until a run writes them.
